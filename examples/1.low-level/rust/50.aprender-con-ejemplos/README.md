**Instalación**

Instalar Rust en OpenSUSE:

* `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

Comprobamos:

```bash
$ rustc --version
rustc 1.96.0 (ac68faa20 2026-05-25)

$ cargo --version
cargo 1.96.0 (30a34c682 2026-05-25)

```
