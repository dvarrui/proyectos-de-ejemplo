# 4. DSL

```
Es interesante encontrar el "match",
pero si no escontramos el lenguaje adecuado
entonces lo creamos.
```

Los lenguajes específicos del dominio (DSL), son lenguajes creados para tener un modelo cognitivo equivalente/cercano al problema que se pretende resolver. Ejemplos:

* Regex (Expresiones Regulares): Solo para buscar patrones en texto.
* YAML / JSON: Solo para representar datos jerárquicos.
* Las matemáticas

Un programador senior sabe identificar qué modelo cognitivo requiere el problema actual y elige la herramienta que tenga la menor distancia posible.

> Relfexión: ¿Es mejor ser un "especialista" en un solo lenguaje o ser un "políglota" que cambia de modelo según el problema?
